# 🍕 Pizza Hut Sales Analysis | SQL Project

## 📌 Project Overview

This project demonstrates how SQL can be used to analyze real-world business data and generate actionable insights for decision-making.

Using a Pizza Hut sales dataset, I designed a relational database and performed exploratory and business-focused analysis with MySQL. The project answers key business questions related to revenue, customer purchasing behavior, product performance, and sales trends.

---

## 🎯 Business Objectives

- Analyze overall sales performance
- Identify top-performing pizzas and categories
- Measure revenue contribution
- Understand customer ordering behavior
- Discover peak ordering hours
- Support business decisions using SQL
